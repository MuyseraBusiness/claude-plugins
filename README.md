# Muysera Claude plugins

A Claude plugin marketplace. Add it in claude.ai under Customize > Plugins > Add > Add marketplace, using https://github.com/MuyseraBusiness/claude-plugins

- muysera-postmark-skills: Postmark's official agent skills, pinned to a reviewed commit of github.com/ActiveCampaign/postmark-skills (ActiveCampaign, MIT).
- muysera-postmark-tools: Postmark's official MCP server (@activecampaign/postmark-mcp 2.1.1) with safety rules. Needs POSTMARK_SERVER_TOKEN set privately; no secrets are stored here.
